# CronosEstudo Android v0.1.0

Primeiro MVP nativo Android para planeamento e controlo de estudos.

## Incluído
- Agenda diária com sessões coloridas
- Criar, concluir, eliminar e reorganizar sessões
- Alarmes locais exatos, quando autorizados pelo Android
- Cronómetro com registo da sessão concluída
- Análise diária e semanal por disciplina
- Armazenamento offline com SharedPreferences
- Tema visual moderno em Jetpack Compose

## Gerar o APK sem instalar ferramentas no PC
1. Crie um repositório no GitHub e envie todo o conteúdo desta pasta.
2. Abra **Actions > Build Android APK > Run workflow**.
3. Após a conclusão, descarregue o artefacto **CronosEstudo-debug-apk**.

O APK de teste estará dentro do ficheiro ZIP descarregado.
